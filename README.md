# Reverse-Engineered Apps Collection

This repository houses multiple reverse-engineered applications. Each project in this collection is contained in its own directory and focuses on deconstructing, analyzing, and rebuilding existing applications using modern AI workflows.

## Tech Stack
These projects are built and analyzed primarily utilizing:
* **Google Antigravity:** For structural deconstruction and logic recreation.
* **Gemini Flash 3.8:** For code generation, automated analysis, and prompt-driven development.

## Structure
Each application lives in its own dedicated folder. Navigate to individual project directories to find specific source code, setup instructions, and documentation for that particular app.
